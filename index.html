JoJo-Mod v1.3.0 — BC R133+

Unlocks and adapts clothes & restraints for flat-chested / male avatars (FlatSmall & FlatMedium) in Bondage Club across all poses (Standing, Yoked, OverTheHead, BackBoxTie, BackCuffs, BackElbowTouch).

Method 1 (Recommended): Install in Violentmonkey / Tampermonkey

Click the button below to install JoJo-Mod in Violentmonkey or Tampermonkey. Once installed, it will load automatically every time you open Bondage Club on any server (Asia, Europe, America):

⚡ Install jojo-mod.user.js (1-Click)

Method 2 (No Extension Needed): Bookmarklet or Console

Note: Bondage Club's FUSAM loader restricts ?fusam= URL parameters to localhost only. If you don't use Violentmonkey, you can load JoJo-Mod on any browser with 1 click using a Bookmarklet or the Console:

Option A (Bookmarklet): Drag this purple button to your browser's Bookmarks Bar, then click it whenever you are in Bondage Club:

🔖 Activate JoJo-Mod (Drag to Bookmarks Bar)

Option B (Console F12): Or copy and paste this line into the browser Console (F12):

import("https://jojo-bc.github.io/JoJo-Mod/jojo-mod.user.js?t=" + Date.now())
