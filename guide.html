How to identify in-game clothing/restraint IDs for male chest adaptation and technical rules for creating custom artwork.

1. How to Identify Any In-Game Item for Adaptation

Bondage Club internal asset names often differ from the English or localized display titles (for instance, Latex Top is technically Suit / 乳胶衣). Use this snippet to inspect exact internal names:

🔍 Asset Inspector Snippet (Paste into Console F12)
(() => {
    const currentGroup = CharacterAppearanceSelection?.FocusGroup?.Name;
    if (currentGroup && typeof DialogInventory !== "undefined" && DialogInventory.length) {
        console.log(`%c=== ITEMS IN WARDROBE SLOT [${currentGroup}] ===`, "color:#d943d4; font-weight:bold; font-size:12px;");
        DialogInventory.forEach(item => {
            const a = item.Asset;
            console.log(`Group: "${a.Group.Name}" | Name: "${a.Name}" | Title: "${a.Description}"`);
        });
        return;
    }

    console.log("%c=== CURRENTLY WORN ITEMS ===", "color:#3b82f6; font-weight:bold; font-size:12px;");
    Player.Appearance.forEach(item => {
        const a = item.Asset;
        console.log(`Group: "${a.Group.Name}" | Name: "${a.Name}" | Title: "${a.Description}"`);
    });
})();

Simply copy the line output by the console (e.g. Group: "Suit" | Name: "乳胶衣" | Title: "Latex Top") and share it. We will run our automated 2D warp engine to generate both FlatSmall and FlatMedium versions across all 6 poses.

2. Technical Rules & Testing in JoJo-Studio

To design clothes or restraints from scratch:

Parameter Requirement
Canvas Resolution 500 × 1000 pixels (exact)
File Format 32-bit PNG (RGBA) with transparent background
Head & Neck y = 0 .. 200
Torso & Arms (`BodyUpper`) y = 200 .. 460
Hips, Legs & Feet (`BodyLower`) y = 460 .. 1000
Center Axis x = 250
🎨 Testing in JoJo-Studio

You can test your custom artwork instantly without opening the game:

  1. Open JoJo-Studio in your browser.
  2. Select your target pose and chest size (FlatSmall, FlatMedium, or FemaleSmall).
  3. Drag & drop your painted PNG directly onto the "Test Custom Artwork" box.
  4. Verify alignment, seams, and fit in real time!
